# Dashboard Screenshot Placeholders

Add final dashboard screenshots here after building the Power BI or Streamlit dashboard:

- `executive_overview.png`: KPI cards for exposure, credit limit, utilization, overdue amount, default rate, high-risk exposure share, expected loss proxy, and watchlist count.
- `exposure_segmentation.png`: exposure by country, industry, company size, and top customers.
- `risk_rating_analysis.png`: exposure by rating, rating migration matrix, downgrade analysis, and outlook distribution.
- `watchlist.png`: high-risk customers, severity, watchlist reasons, recommended actions, and exposure at risk.
- `stress_testing.png`: baseline versus downturn scenarios, stressed loss proxy, incremental loss proxy, affected customers, and commentary.

These files should be generated from the dashboard built on `output/powerbi/powerbi_credit_risk_dashboard.csv` and `output/stress_tests/stress_test_results.csv`.
